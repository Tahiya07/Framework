
\section{Summary of the Work}
This project delivered a lightweight, multi-modal, privacy-oriented academic assistant for universities. Students receive RAG-based answers from public learning corpora; teachers receive Bloom-level labels, probabilities, and generative moderation text. PrivacyGuard and federated components limit exam reconstruction risks.

\section{Key Findings and Contributions}
\begin{itemize}
    \item Integrated pipeline: PyMuPDF + OCR + MiniLM + FAISS + Qwen GGUF + LoRA Bloom + federated privacy.
    \item Role-separated corpora and auditable screening policies for student vs teacher flows.
    \item Reproducible evaluation harness producing unified CSV/JSON tables for reporting.
    \item Federated teacher LoRA simulation with encrypted parameter bundles and FedAvg aggregation.
\end{itemize}

\section{Limitations of the Study}
Simulation-based federation, limited benchmark scale, and dependency on manual threshold tuning for privacy guard remain key limitations. Generative moderation quality was not evaluated with human expert inter-rater studies.

\section{Recommendations and Future Work}
\begin{itemize}
    \item Deploy true multi-node federation with secure aggregation and key management.
    \item Conduct expert moderation studies measuring time saved and inter-rater agreement.
    \item Extend student federated RAG LoRA only on public materials per institution.
    \item Integrate differential privacy accountants tuned for production $\varepsilon$ targets.
    \item Add Bangla/English multilingual ingestion for local universities.
\end{itemize}

\section{Chapter Summary}
The work demonstrates feasibility of on-premises academic AI with explicit privacy mechanisms. Future effort should focus on production hardening and larger-scale validation.
