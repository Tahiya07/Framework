\chapter{Appendix A: Evaluation Artifacts}
\label{appendix:eval}
Reproducible outputs are stored in the project repository:
\begin{itemize}
    \item \texttt{results/unified\_results\_table.csv} -- consolidated metrics.
    \item \texttt{results/qwen\_rag\_eval.json} -- RAG benchmark.
    \item \texttt{results/privacy\_guard\_eval.json} -- privacy evaluation.
    \item \texttt{evaluation\_results/metrics.json} -- Bloom LoRA test metrics.
    \item \texttt{run\_evaluation\_pipeline.py} -- regeneration script.
\end{itemize}

\chapter{Appendix B: Federated Learning Protocol}
\label{appendix:fl}
Teacher LoRA federation is executed via \texttt{federated/run\_simulation.py}: local training (\texttt{client\_train.py}), encrypted bundles (\texttt{secure\_bundle.py}), server FedAvg (\texttt{server\_aggregate.py}). Privacy-guard federation uses \texttt{privacy/train\_federated\_privacy\_guard.py}.

\chapter{Appendix C: User Manual (Demo)}
\label{appendix:demo}
\begin{enumerate}
    \item Install dependencies: \texttt{pip install -r requirements.txt}.
    \item Train or obtain LoRA weights; run \texttt{python merge\_model.py}.
    \item Launch demo: \texttt{streamlit run streamlit\_app.py}.
    \item Upload public PDFs for student RAG; upload protected items only in teacher mode.
\end{enumerate}
